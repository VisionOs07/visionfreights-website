# Vision Freight Logistics V6.0 — Deployment

1. Copy the contents of this folder into your existing Git repository.
2. Run `git status` and review changed files.
3. Run `git add .`
4. Run `git commit -m "Vision Freight Logistics Website V6.0 - Production Release"`
5. Run `git push`
6. Wait for Cloudflare Pages to report a successful deployment.
7. Open https://www.visionfreights.com in a private window and test Home, Solutions, Quote, Tracking and Contact on desktop and mobile.
